## Short Description
Coding and digital-record skills for insurance, analytics and NABH's digital push.

## Full Description
This certification-grade course covers ICD coding conventions, chapter structure, principal and secondary diagnosis selection, procedure coding, common coding errors, and the use of hospital information systems and electronic medical records for capture, discharge summaries and claims. Accurate coding supports insurance and Ayushman Bharat claims, clinical audit and the health information requirements of the NABH 6th Edition standard.

## Course Objectives
1. Explain ICD structure, conventions and the rules for code selection
2. Apply coding guidelines to select principal and secondary diagnoses accurately
3. Use hospital information system and electronic medical record functions for clinical documentation
4. Identify documentation gaps that lead to coding errors and claim rejections

## Course Learning Outcomes
1. Learners can code a complete inpatient case record without supervision
2. Learners can query clinicians appropriately when documentation is unclear or incomplete
3. Learners can prepare coded data for insurance claims and clinical audit
4. Learners can navigate the hospital information system to retrieve and verify records

## Who Can Take This Course
Medical records officers, coders, billing and insurance desk staff, health information management staff, Medical Officers, discharge summary writers, quality coordinators, IT staff and health information management students.
