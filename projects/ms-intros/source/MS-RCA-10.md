# Root Cause Analysis & Incident Reporting (MS-RCA-10)

## Course Code
MS-RCA-10

## Course Name
Root Cause Analysis & Incident Reporting

## Category
Patient Safety & Clinical Risk

## Course Type
Upskilling

## Learning Hours
6

## Short Description
Build a just reporting culture and turn incidents into system fixes.

## Full Description
This course teaches incident reporting, near-miss capture, severity grading, timeline construction, cause-and-effect analysis, the five whys method and corrective and preventive action planning. NABH 6th Edition requires hospitals to report, analyse and learn from sentinel events and adverse events. The course also addresses building a just culture so that staff report freely and findings translate into system changes rather than individual blame.

## Course Objectives
1. Explain the principles of a just culture in incident reporting
2. Apply structured root cause analysis methods to adverse events and near misses
3. Identify system and human factors contributing to patient safety incidents
4. Plan corrective and preventive actions with owners, timelines and verification

## Course Learning Outcomes
1. Learners can complete an incident report with accurate, factual and timely detail
2. Learners can facilitate a root cause analysis meeting for a moderate severity event
3. Learners can distinguish system causes from individual error in incident review
4. Learners can track corrective actions to closure and measure their effect

## Who Can Take This Course
Quality managers, patient safety officers, Medical Officers, consultants, ward in-charges, staff nurses, pharmacists, laboratory and radiology staff, and administrators responsible for incident review committees.
