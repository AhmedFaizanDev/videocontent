# Code Blue & Rapid Response Team (MS-CODE-38)

## Category
Emergency & Critical Care

## Course Type
Mandatory

## Learning Hours
6

## Short Description
Run effective codes and mock drills — a functioning code team NABH expects.

## Full Description
This course prepares hospitals to run effective cardiac arrest responses. It covers recognition of arrest and peri-arrest states, activating the code blue call, team roles, high quality chest compressions, defibrillation, airway and drug support, closed loop communication, post-resuscitation care, debriefing and documentation. NABH 6th Edition expects a trained code team, defined response times and recorded mock drills across all hospital areas.

## Course Objectives
1. Explain code blue activation, response times and defined team member roles
2. Demonstrate high quality chest compressions, bag mask ventilation and defibrillator use
3. Apply closed loop communication and leadership during a resuscitation attempt
4. Plan mock drills and debriefings that improve future team performance

## Course Learning Outcomes
1. Learners can activate a code and begin compressions within seconds of recognition
2. Learners can take an assigned role in the code team without confusion
3. Learners can complete the code blue record and post-resuscitation handover accurately
4. Learners can run a mock drill and capture improvement points in debriefing

## Who Can Take This Course
All clinical staff including doctors, staff nurses, technicians and therapists, plus security, housekeeping and front office staff who may witness collapse; required annually for clinical staff and code team members.
